# Overmax

[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md)

DJMAX RESPECT V の選曲画面で、V-Archive ベースの非公式難易度情報をリアルタイムに表示するオーバーレイツールです。

> **🚀 Rust ネイティブアプリ**: Overmax は Rust ネイティブで構築されており、軽量かつ高速な動作を実現しています。
> - **軽量・高速**: メモリ使用量と実行ファイルサイズを最小限に抑え、全体的なランタイム性能に優れています。
> - **外部依存の最小化**: 重い OpenCV に依存せず、純粋な Rust 実装の HOG ジャケット画像マッチングと Windows 標準 OCR を活用しています。
> - **完全な下位互換性**: 既存ユーザーの設定 (`settings.json`) やローカル記録 (`record.db`) と互換性があり、既存のポータブル環境をそのまま利用できます。

## ユーザーガイド

### 何をしてくれるの?

選曲画面で現在選択されている曲の **V-Archive 非公式難易度** と **類似難易度のおすすめリスト** を、ゲーム画面の横に表示します。

- 現在選択中の曲のボタンモード別非公式難易度を表示 (NM/HD/MX/SC)
- **V-Archive 記録連携**: V-Archive のプレイ記録を取り込み、ローカルで収集した記録を V-Archive に登録可能
- **リアルタイム Rate / Max Combo 収集**: ゲーム内で記録が更新されると自動的に検出し、ローカルに保存(リアルタイムで自己ベストを検出した際は V-Archive への簡単アップロードにも対応)
- **類似難易度のおすすめ**: 現在のパターンと難易度が近い他のパターンをおすすめ表示(Rate が低い順 → 未プレイ順)
- **ライトモード (Lite Mode)**: おすすめリストなど不要な要素を非表示にし、曲情報やリアルタイム Rate など必要最小限の情報のみを表示するコンパクトなレイアウト(縦幅約60px程度)を提供します。
- **リアルタイム新記録・簡単アップロード通知**: プレイ中に検出された Rate が既存の V-Archive 記録を上回った場合、オーバーレイヘッダーの **アップロードボタン(⬆)** が有効になり、最新の記録を簡単に V-Archive へ反映・アップロードできます。

メモリ読み取りやゲームファイルの改変は一切行わず、**ウィンドウ追跡 + 画面キャプチャ** のみで動作します。

### インストール方法

1. [Releases](https://github.com/orphera/overmax/releases) から最新版の `overmax.zip` をダウンロードします。
2. 解凍して `overmax.exe` を実行します。
3. 実行中に DJMAX RESPECT V を起動すると、自動的に認識が開始されます。

> **自動アップデート**: アプリ起動時に最新バージョンと曲DB (`image_index.db`) の状態を自動的に確認し、更新を行います。

### 動作環境

- Windows 10 1809 以降 (64bit) — Windows OCR が必須
- DJMAX RESPECT V (Steam)
- 実行中のインターネット接続 (V-Archive データのダウンロード、アプリ・DBの自動アップデート確認に使用)

> ⚠️ **重要: ゲーム画面設定について**
> * **ボーダーレスフルスクリーン(全画面ウィンドウモード)推奨**: オーバーレイウィンドウをゲーム画面の上に正しく表示してプレイするには、ゲームの画面設定を **「ボーダーレスフルスクリーン」** にしてください。
> * **排他的フルスクリーンを使用する場合**: ゲームを通常の **「フルスクリーン」** モードで実行すると、Windows OS およびゲームのアンチチート (XIGNCODE3) の制約により、オーバーレイがゲーム画面の上に描画されず、背後に隠れてしまいます。排他的フルスクリーンを必ず使用する必要がある場合は、オーバーレイウィンドウをドラッグして **デュアルモニターのサブモニター** など、別のモニター領域に配置して使用してください。

> **補足**: 設定からオーバーレイUIの言語を英語または日本語に切り替えることができます(デフォルトは韓国語です)。

### 設定

- オーバーレイヘッダーの **歯車ボタン(⚙)** をクリックすると設定画面が開きます。
- 設定画面では **オーバーレイサイズ (S / M / L / XL)** と **透明度** を調整できます。
- オーバーレイは egui のネイティブドラッグ機能を利用しているため、マウスドラッグで自由に位置を移動でき、位置は自動的に保存されます。
- 設定画面から **ライトモード** を有効にできます。ライトモード有効時は意図しないドラッグ移動がブロックされ、設定した画面隅(左上・右上・左下・右下)へジッターなく自動的にスナップ・固定されます。

## 開発者ガイド

### ビルドと実行

```bash
# Rust のインストールが必要 (rustup)
cargo build --release -p overmax-app
./target/release/overmax.exe
```

### プロジェクト構成 (Rust)

- `rust/overmax_app`: メインアプリケーション (egui/winit ベースの UI およびイベントループ)
- `rust/overmax_core`: コア状態モデルおよび共通ロジック
- `rust/overmax_data`: 設定、DB (SQLite)、V-Archive API 連携
- `rust/overmax_cv`: 画像処理コアアルゴリズム (HOG、OCR前処理など)

### ビルド・リリーススクリプト

- `scripts/package-rust.ps1`: ビルドおよびリリース用の `overmax.zip`、`release_manifest.json` を生成する自動化スクリプト(既存のリリース構成と同一形式を維持)
