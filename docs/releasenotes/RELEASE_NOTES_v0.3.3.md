# Overmax v0.3.3 릴리즈 노트

> v0.3.2 이후 변경 사항 (v0.3.3)

---

## 🎮 일반 사용자를 위한 주요 변경 사항

### 🖥️ 1. 다중 모니터 및 보조 디스플레이 버그 수정
* **보조 모니터 게임 구동 정상 지원**: 메인 모니터가 아닌 보조 모니터에서 게임을 실행할 때 화면을 인식하지 못하던 문제를 해결했습니다.
* **모니터 간 배율(DPI) 불일치 시 오작동 해결**: 주 모니터와 보조 모니터의 화면 배율 설정(예: 100%, 150%)이 서로 다를 때 오버레이 위치가 어긋나거나 인식이 빗나가던 현상을 수정했습니다.
* **창 모서리 스냅 위치 오차 보정**: 고해상도 및 다중 모니터 환경에서 오버레이를 화면 모서리에 붙일 때 발생하던 위치 어긋남을 바로잡았습니다.
* **오버레이 배경 검은색 깜빡임/노출 해결**: 윈도우 환경에 따라 오버레이 뒤에 검은색 사각형 배경이 순간적으로 나타나던 현상을 수정하여 투명 배경이 깔끔하게 유지됩니다.
* 💡 **다중 모니터 이용 팁**: 기본값인 `Auto` 모드에서 자동으로 최적화되지만, 특정 다중 모니터 환경이나 GPU 구성에 따라 DXGI 캡처 시 인식이 원활하지 않은 경우 **설정 → 캡처 방식**을 `GDI`로 변경하시면 안정적으로 이용하실 수 있습니다.

### ⚡ 2. 인게임 성능 영향 및 CPU 점유율 완화
* **인게임 프레임 드랍 완화**: 게임 플레이 도중 발생할 수 있었던 화면 분석 지연을 줄여 게임 플레이에 미치는 영향을 최소화했습니다.
* **선곡창 대기 중 CPU 점유율 최적화**: 곡 목록 화면에서 픽셀 변화가 없을 때 불필요한 반복 연산을 건너뛰도록 개선했습니다.

### ⚙️ 3. 화면 캡처 성능 개선 및 적응형 자동 선택 (`Auto (추천)`)
* **적응형 백엔드 (`Auto`) 기본 적용**: 단일 모니터 환경에서는 고성능 캡처(DXGI)를, 다중 모니터 환경에서는 호환성이 높은 캡처(GDI)를 자동으로 선택합니다.
* **캡처 지연시간 단축**: 화면 캡처 소요 시간을 단축하여 전체적인 시스템 리소스 소모를 줄였습니다.
* **런타임 백엔드 즉시 변경**: 설정창에서 캡처 방식을 변경할 때 앱 재시작 없이 즉시 적용됩니다.

### 🌐 4. 한국어 / 영어(English) 공식 다국어 지원
* **영어 인터페이스 추가**: 한국어와 영어를 지원하며, 시스템 언어 설정에 따라 자동 전환되거나 설정창에서 직접 변경할 수 있습니다.
* **영문 사용자 안내서 제공**: 영문 README 및 사용자 가이드가 함께 제공됩니다.

### 🖱️ 5. 오버레이 창 이동 및 편의성 개선
* **부드러운 창 드래그**: OS 네이티브 창 이동 방식으로 개선하여 고주사율 모니터 환경에서도 자연스럽게 창을 이동할 수 있습니다.
* **게임 창 뒤 가려짐 현상 수정**: 게임 실행이나 포커스 전환 시 오버레이가 게임 창 뒤로 숨겨지던 문제를 해결했습니다.
* **오버레이 배치 방향 버튼 개선**: 설정창의 배치 위치 버튼을 직관적인 심볼(▲, ▼, ◀, ▶)로 변경했습니다.
* **오버레이 항상 표시 옵션 추가**: 씬 감지 상태와 무관하게 오버레이를 상시 띄워둘 수 있는 옵션이 추가되었습니다.

### 🚀 6. 앱 실행 초기 지연 개선
* 앱 시작 시 캐시 데이터 갱신을 비동기 백그라운드 작업으로 분리하여 실행 즉시 창이 열리도록 개선했습니다.

### 🐧 7. Linux 환경 지원 강화
* **창모드 캡처 지원**: 전체화면뿐만 아니라 창모드로 실행된 게임 화면도 인식할 수 있습니다.
* **다중 모니터 지원**: 다중 출력 환경에서 오버레이 위치 지정 및 렌더링 호환성을 개선했습니다.

## 🛠️ 개발자를 위한 기술 변경 및 아키텍처 개선 사항

### 🖥️ 1. 다중 모니터 DPI 인식 및 캡처 디스플레이 동적 매핑
* **Per-Monitor DPI Aware V2 및 물리 좌표 추적**:
  * 서로 다른 DPI 배율의 모니터 환경에서 발생하던 Win32 DPI 가상화 좌표 왜곡을 방지하기 위해 Per-Monitor DPI Aware V2 컨텍스트를 선언하고, `DwmGetWindowAttribute` 및 `ClientToScreen` 물리 픽셀 좌표 기반으로 윈도우 경계를 추적하도록 개선했습니다.
* **DXGI 서브 모니터 `Output1` 동적 탐색 및 로컬 오프셋 변환**:
  * DXGI 백엔드 사용 시 게임 창의 중심 좌표를 기반으로 활성 DXGI 디스플레이 Output을 동적으로 탐색하고 캡처 크롭 좌표 오프셋을 변환하도록 구현했습니다.
* **오버레이 Scale 피드백 루프 해소 및 높이 Auto-Fit**:
  * 스케일 변경 시 이전 뷰포트 크기가 창 크기를 덮어쓰던 피드백 루프를 제거하고, Width 고정 + egui 렌더 응답 높이(`rect.height()`) 동적 핏을 적용했습니다.

### 🎯 2. CV 디텍션 파이프라인 1-Pass 전환 및 Centroid Kernel Gate
* **Score 1-Pass 단독 매칭 ($\text{Rate} = \text{Score} / 10000.0$)**:
  * 소수점/퍼센트 기호 매칭 및 교차 검증을 제거하고, 7자리 정수 Score 단독 매칭으로 Rate를 산출하도록 단순화하여 속도와 인식률을 개선했습니다.
* **1차 Centroid Kernel 사전 게이트 도입**:
  * 4x4 RGBA 히스토그램 대표 중심점(Centroid)을 이용한 사전 게이트를 배치하여, 비자켓 프레임에서 전체 DB 순회 연산이 일어나지 않도록 조기 차단(Early Exit)했습니다.
* **선곡창 Mode / Diff / Score ROI 픽셀 체크섬 캐싱**:
  * 입력 픽셀 체크섬이 동일한 경우 템플릿 매칭을 스킵하고 5초 강제 재검증(`force_recheck`) 타이머를 제거하여 정적 상태 연산을 절감했습니다.
* **3단계 카테고리 띠(Category Band) 단독 게이트**:
  * 밝기, 수직 단색성, 채도 3단계 통계 판정을 적용하여 BGA 간섭에 강건한 씬 판별을 확립했습니다.

### ⚡ 3. 캡처 백엔드 DWM 락 소거 및 DXGI Fail-Safe
* **GDI `BitBlt` `CAPTUREBLT` 플래그 제거**: Windows DWM 수직 동기화 락으로 인한 블로킹 지연을 소거했습니다.
* **DXGI `ACCESS_LOST` 예외 처리 및 GDI 자동 폴백**: 해상도/전체화면 전환 시 3초 쿨다운을 거쳐 GDI 백엔드로 안전하게 자동 폴백하도록 방어했습니다.

### 🌐 4. Zero-Cost / 0-Allocation `t!` 다국어(i18n) 시스템
* **컴파일 타임 상수 룩업**:
  * 런타임 문자열 치환과 힙 할당을 제거하고, `@select` 매크로와 `lookup_ko`/`lookup_en` 1:1 대칭 룩업(SSOT)을 통해 0-Cost 다국어 디스패치를 구현했습니다.

### 💾 5. 메모리 및 SQLite 데이터 계층 최적화
* **`VArchiveDB.title_map` 인덱스화**: `HashMap<String, Vec<usize>>` 인덱스 구조로 전환하여 상주 메모리를 절감했습니다.
* **`RecordDB.get_rate_map` 커넥션 캐싱**: `thread_local!` SQLite 커넥션 재사용을 통해 반복 오픈 오버헤드를 완화했습니다.
* **`StartupCacheManager` 캡슐화**: 시작 시 캐시 갱신을 Non-blocking 비동기 Worker + `ArcSwap` 구조로 캡슐화했습니다.

### 📊 6. 고해상도 마이크로초(`µs`) 텔레메트리 & 세션 로거
* **마이크로초(`µs`) 정밀 계측**: `capture`, `detect`, `scene`, `jacket`, `play` 지표를 힙 할당 없이 계측합니다.
* **KST 타임스탬프 & `[SceneTransition]` 이벤트 로깅**: 밀리초 단위 시각과 씬 전이 이벤트를 기록합니다.
* **게임 세션별 롤링 & `telemetry` Feature 분리**: 게임 재기동 시 세션 로그를 자동 롤링하며, 배포용 릴리스 빌드 성능 보호를 위해 `--features telemetry` 플래그로 분리했습니다.
