# Overmax v0.3.3 릴리즈 노트

> v0.3.2 이후 변경 사항 (v0.3.3)

---

## 🚀 주요 신규 기능 및 사용자 변경 사항

### ⚙️ 1. 오버레이 및 캡처 설정 옵션 강화 (DXGI 백엔드 기본값 전환)
* **DXGI 캡처 백엔드 기본값 전환**:
  * 이전까지 GDI 기반으로 동작하던 캡처 방식을 성능과 안정성이 높은 **DXGI 백엔드 기본값**으로 공식 전환했습니다. (필요 시 설정창에서 GDI 방식으로 변경 가능)
* **오버레이 항상 표시 옵션 (`overlay.always_visible`)**:
  * 설정창 `오버레이` 탭에 "오버레이 항상 표시" 옵션이 추가되었습니다. 인게임 씬 감지 여부와 상관없이 오버레이를 화면에 항상 띄워둘 수 있습니다.
* **화면 캡처 방지 옵션 및 주의사항 안내**:
  * 방송/녹화 프로그램(OBS 등)에서 오버레이를 숨기거나 노출할 수 있는 "화면 캡처 방지" 옵션이 제공됩니다.
  * ⚠️ **주의사항**: 화면 캡처 방지를 해제(끄기)하면 방송/녹화 화면에 오버레이가 잡히는 대신, 오버레이가 인게임 중요 영역을 가릴 경우 곡 인식을 방해할 수 있으니 주의해서 사용해 주세요.

### 🖱️ 2. 오버레이 이동 편의성 개선 (부드러운 창 드래그 & 화면 뒤 가려짐 방지)
* **부드러운 창 드래그 (덜덜 떨림 0%)**:
  * 오버레이 상단바를 잡고 이끌 때 뚝뚝 끊기거나 덜덜 떨리던 현상을 완벽히 해결하여, 손끝에 붙어 부드럽게 창을 이동할 수 있습니다.
* **창 가려짐 현상 근본 해결**:
  * 디제이맥스 게임 창을 켜거나 포커스를 이동할 때 오버레이가 게임 화면 뒤로 파묻혀 사라지던 현상을 근본적으로 해결했습니다.

## 🔧 개발자 및 고급 디버깅 도구 (Advanced / Hidden Settings)

### 📊 1. 실시간 실행 상태 진단 대시보드
* **숨김 설정 기반 디버그 대시보드**:
  * 사용자 설정 파일(`settings.user.json`)의 숨김 옵션을 통해 기동되는 100ms 실시간 디버그 패널입니다.
  * 캡처 엔진, 포커스 상태, 오버레이 투명도, 씬 인식 결과 등 시스템 내부 실행 상태를 진단할 수 있습니다.
